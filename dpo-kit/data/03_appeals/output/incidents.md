# Инциденты по обращениям граждан

## LIGHT-01 — Уличное освещение (ул. Сосновая, 12)
**Объект:** LIGHT-01
**Тип:** Уличное освещение
**Обращения (4):**
- A001 — Не горит фонарь возле дома
- A002 — Вечером темно около подъезда
- A004 — Освещение не работает уже неделю
- A006 — Просим проверить фонари

## LIGHT-02 — Уличное освещение (ул. Сосновая, 14)

**Тип:** Уличное освещение
**Обращения (2):**
- A003 — Темно рядом с домом 14
- A005 — Неисправна уличная лампа

## CROSS-01 — Пешеходный переход (школа № 7)
**Объект:** CROSS-01
**Тип:** Пешеходный переход
**Обращения (4):**
- A007 — Переход у школы плохо освещён
- A008 — На пешеходном переходе темно
- A009 — Плохая видимость на зебре
- A010 — Опасно переходить дорогу вечером

## WATER-01 — Водопровод (ул. Речная, 5)
**Объект:** WATER-01
**Тип:** Водопровод
**Обращения (3):**
- A011 — Вода течёт из-под асфальта

- A014 — Течь до сих пор не устранена

## BUS-01 — Остановочный павильон (остановка Центральная)
**Объект:** BUS-01
**Тип:** Остановочный павильон
**Обращения (3):**
- A015 — Нет расписания автобусов
- A016 — Стенд с расписанием сломан
- A017 — Невозможно узнать время рейсов
